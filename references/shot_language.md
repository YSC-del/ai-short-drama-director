# 镜头语言词典

写分镜表与生成视频提示词时，只使用本文件的词。自定义词会造成模型理解不一致。

---

## 一、景别（shot_size）

| 词 | 用途 | 情绪 |
|---|---|---|
| 大远景 | 开场、环境交代、孤独感 | 疏离 |
| 远景 | 人物全身 + 环境关系 | 交代 |
| 全景 | 动作完整性、打斗、追逐 | 张力 |
| 中景 | 日常对话、交易、对峙 | 中性 |
| 近景 | 情绪、表情、关键反应 | 亲密 |
| 特写 | 道具、手部、眼神、关键信息 | 强调 |
| 大特写 | 瞳孔、泪、血滴、屏幕文字 | 冲击 |
| 过肩 | 双人对峙、偷窥、关系位差 | 对峙 |
| 主观视角 | 代入、恐怖、第一人称 | 沉浸 |

**专业缩写**（分镜表与英文提示词通用）：大远景 ELS、远景 LS、全景 FS、中景 MS、近景 MCU、特写 CU、大特写 ECU、过肩 OTS、主观视角 POV。机位角度：低仰拍 Low Angle、高俯拍 High Angle、平视 Eye Level、鸟瞰 Bird's Eye、荷兰角 Dutch Angle（倾斜构图，仅心理失衡时用）。

竖屏注意：特写占比提高（人脸在竖屏中更易占满），但连续特写不超过 3 个，否则视觉疲劳。

### 镜头功能类型（与景别正交，按戏剧功能选）

以下类型和景别组合使用（如"反应镜头=近景"、"插入镜头=特写"），对话戏必备，词表见上：

| 类型 | 英文 | 用途 |
|---|---|---|
| 双人镜头 / 侧面双人 | `two-shot`, `profile two-shot` | 对峙、亲密、权力关系；对话第一个镜头必须用它建立左右关系 |
| 过肩 | `over-the-shoulder` | 施压、倾听、保留反应；权力不对等时从高位一方肩后拍 |
| 反应镜头 | `reaction shot` | 听者表情变化；情绪反转的落点；每句重要台词至少配一个 |
| 插入镜头 | `insert shot` | 承载剧情的道具（合同、手机、戒指、伤口、门把手）；让 AI 对话有"剪辑感" |
| 空镜头 | `empty shot` | 缺席、等待、善后；转场或情绪落点，每集 1-2 个 |

对话戏的轴线、站位与覆盖模式见 `references/dialogue-coverage.md`；光型的情绪用途见 `references/cinematic-dictionary.md` 第五节。

## 二、运镜（camera）

| 词 | 效果 | 适用 |
|---|---|---|
| 固定 | 稳定、观察、克制 | 对话、审讯 |
| 推 | 强调、进入内心、发现 | 揭示、情绪 |
| 拉 | 抽离、孤独、关系破裂 | 结尾、告别 |
| 摇 | 环视、搜索、扫视 | 悬疑、恐怖 |
| 移 | 跟随、平行、横向关系 | 追逐、并行 |
| 跟 | 贴人物、紧迫 | 追逐、逃跑 |
| 升 | 宏大、神启、升华 | 觉醒、登顶 |
| 降 | 压迫、下沉、失控 | 坠落、危机 |
| 手持 | 纪实、慌乱、直播感 | 惊悚、打斗 |
| 环绕 | 炫技、登场、展示 | 变身、亮相 |
| 甩镜 | 快切、冲击 | 动作、反转 |
| 长镜 | 沉浸、时间流逝 | 情绪、文艺 |

每个分镜只能有 **一个主运镜**。多个动作写进 `action`，不要写"推拉摇移"。

## 三、构图（composition）

三分法 / 中心对称 / 框架构图（门窗、后视镜）/ 对角线 / 前景遮挡 / 低角度仰拍 / 高角度俯拍 / 对称压迫 / 大面积留白 / 封闭构图 / 镜像反射。

竖屏构图：主体放上 2/3，下方留安全区给字幕；关键信息避开屏幕底 25%。

---

## 四、光线（lighting）

自然光 / 窗光 / 霓虹 / 烛光 / 顶光 / 逆光剪影 / 伦勃朗光 / 冷暖对比 / 体积雾光 / 屏幕冷光 / 审讯顶灯 / 阳光斑驳。

**光型分三层，逐级兜底**：`shots[].lighting`（本镜特殊光效）→ `scenes[].lighting`（场景默认光型）→ `styles.json` 的 `lighting`（风格默认）。

- 风格 `lighting` 只是**日戏/常规室内**的默认值；**夜外、雨雪、烛火、剪影等场景必须在 `scenes[].lighting` 写场景光型**，不要硬套风格默认（否则夜雪外景会得到"窗光暖光"这种荒谬结果）
- 具体某镜有特殊光效（闪白、推入黑暗、逆光剪影）时再写 `shots[].lighting`
- 光型必须与风格体系一致：不要在有电影感风格的剧里混入二次元打光语言；但场景明暗现实优先于字面照抄

选光型 = 选情绪：逆光=分离/神圣，顶光=审判/压迫，侧光=对峙/人格分裂，低调=神秘/痛苦，黄金时刻=温柔/告白。完整光型情绪表见 `references/cinematic-dictionary.md` 第五节。

## 五、转场（transition）

硬切 / 匹配剪辑 / 遮挡转场 / 甩镜转场 / 闪白 / 叠化 / 跳切 / 黑屏。

规则：转场写在镜头的 `transition_in` 字段（schema.md），不是画面提示词。全剧转场以硬切为主（≥70%），其余按情绪点使用。

## 六、镜头时长 × 情绪（production.json → pacing）

| 情绪 | 时长 |
|---|---|
| 追逐 / 紧张 / 动作 | 1-1.5s |
| 揭示 / 高潮 / 卡点 | 2s |
| 日常对话 | 3-5s |
| 情绪 / 静态 | 4-5s |
| 空镜 / 开场环境 | 3-6s |
| 长镜头 / 一镜到底 | 6-30s |

**硬约束：单镜时长 0.5-30 秒。** 超过 30 秒必须拆成两个镜头（用遮挡转场或动作匹配拼接）。

长镜头（>10s）的正确用法：
- 只用于**一个连续动作**（推门→走到桌前→坐下），中间不切
- 人物全程在画面内，且只有 1-2 人
- 必须有明确的**起幅与落幅**（从静止开始，到静止结束）
- 每集最多 1 个长镜头，且不放第 1 集（第 1 集要快）

## 七、镜头配比（按场次类型）

| 场次类型 | 近景 | 中景 | 远景/全景 | 说明 |
|---|---|---|---|---|
| 对话戏 | 50% | 35% | 15% | 过肩 + 反应镜头交替 |
| 动作戏 | 40% | 30% | 30% | 全景建立空间后切近景 |
| 情绪戏 | 60% | 25% | 15% | 少即是多 |
| 开场交代 | 0% | 30% | 70% | 但前 3 秒必须有人物动作 |

## 八、每镜必备字段

分镜表里每个镜头必须有：`shot_no`、`scene_id`、`characters`、`shot_size`、`camera`、`composition`、`action`、`duration_sec`。除 `shot_no`（缺失/非整数记 WARN）外，缺任何一项都进不了生成阶段（`validate_project.py` 报 ERROR）。

推荐但非必须：`lighting`（缺省自动取风格光型，保证每条图片提示词的光线 slot 齐全）、`dialogue` / `narration`（无对白旁白时省略）、`transition_in`（默认硬切）。

特殊要求：换场景的镜头必须带 `scene_marker: true`，否则系统误判卡审（`validate_project.py` WARN）。

# 平台卡审规则（人读版）

机器可读版：`assets/presets/review_rules.json`。`validate_project.py` 对剧本/分镜文本强制执行，`build_prompts.py` 对提示词强制执行，负面提示词自动注入画面禁用元素。写剧本、分镜、提示词前通读本文件；命中规则时按"替换指南"改写，不要模糊处理。

规则来源：`短剧的卡审制度`（平台审核实践整理）。不替代具体平台最新审核标准，交付前提醒用户人工复核。

---

## 一、两级severity

| 级别 | 含义 | 脚本行为 |
|---|---|---|
| `forbidden` 禁止 | 出现即卡审 | ERROR，**必须改写** |
| `avoid` 避免 | 避免或少量出现 | WARN，出现时**该集结尾必须回正**（和解、受惩或明确批判） |

## 四、结构性规则（易被忽略但必卡）

1. **换场景必须有视觉标识**（空镜、门牌、字幕地名、环境音变化），否则系统误判卡审。`project.json` 中用 `shots[].scene_marker: true` 标记。
2. 脏话不出现在字幕：拼音或谐音字代替；侮辱人格的直接删除。
3. 人民币及一切现实币种禁止出现。
4. 演员不得撞脸明星、短剧演员、乙游形象；角色五官必须原创。
5. 架空一切历史和现实：朝代、城市、公司、机构全部虚构。
6. 男女亲密戏只在地上或墙上，且不得有喘息声。
7. 公职人员（警察、医生、教师、护士、消防员）不得为反派、不得渎职。
8. 血腥、恐怖、密集画面不做特写，改镜头外处理。
9. 主角团不得干坏事；主线行为必须合法合规。
10. 所有 avoid 级内容若出现，该集结尾必须回正。

## 五、替换指南

| 原元素 | 替代 |
|---|---|
| 货币 | 牛皮纸袋子、金条、银元宝、布帛、铜钱（古代题材） |
| 抽烟 | 喝茶、嚼槟榔替代物、踱步、按太阳穴 |
| 墙体标语 | 年画、奖状、挂历、plain 木门板 |
| 真实城市 | 虚构城市名（临江市、云川市） |
| 真实公司 | 虚构公司名（恒瑞集团、星海传媒） |
| 血腥 | 镜头外 + 声音 + 角色表情 |
| 脏话字幕 | 拼音或谐音字（"去4"、"么的"） |
| 亲密戏 | 地面/墙上，切反应镜头，无喘息声 |

## 六、脚本如何执行

- `validate_project.py`：扫描标题、角色锚点、场景锚点、每集 hook/cliffhanger、镜头 action/action_en/video_action_en/narration/dialogue/props。forbidden → ERROR（退出码 1）；avoid → WARN（`--strict` 下也阻断）。另检查换场景标识（`scene_marker`）与长镜头规则（>10s，WARN）。
- `build_prompts.py`：扫描每条生成的图片/视频/配音提示词。forbidden → 报错并列出条目（退出码 1）；avoid → 提醒。负面提示词自动注入 `image_negative` / `video_negative` 中的画面禁用元素。
- **豁免机制（白名单）**：中文子串匹配会误伤合法语境（剧名「杀疯了」、「操场上升国旗」）。两处豁免短语来源，合并生效：
  - 全局：`assets/presets/review_rules.json` 的 `text_whitelist`
  - 项目级：`project.json` 的 `meta.review_whitelist`（剧名、固定台词等本项目专属）
  - 判定口径：关键词命中区间**完全落在**某个豁免短语内则不报；短语外的命中照常报出。豁免只是绕开文本扫描，画面负面提示词注入不受影响——敏感画面该避开仍要避开。
- 已知误伤：动作戏里的"粗重喘息"会命中 R04（性行为）关键词——**写"呼吸急促/粗重呼吸声"**即可，不必改写情节。
- 命中规则时的三步降级（改变动作本身 → 改变责任归属 → 改变结果）见 `references/compliance.md` 第三节。

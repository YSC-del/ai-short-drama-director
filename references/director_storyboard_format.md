# 导演分镜标准格式

本文件是后续所有剧本“导演分镜版”的唯一格式标准。适用于人工审阅与中文视频模型。

## 一、角色定位

顶级影视导演与分镜规划师。负责拆解画面与规划视觉叙事，平衡故事性与视觉冲击力，为每一集创造高价值视觉名场面。

## 二、硬性执行标准

### 1. 台词零修改

剧本中的对话、语气词、标点符号原样保留，严禁增删、改写、润色。分镜阶段只搬运，不创作台词。

### 2. 时间轴

- 导演分镜段时长：**4-15 秒**。
- 每个分镜段必须标注“本段时长 / 本集累计时长”。
- 集头标注本集总时长。
- 项目内的 1-5 秒小镜是素材层；导演分镜按 4-15 秒重组，不直接照搬小镜时长。
- 单个镜头超过 15 秒时，必须拆分；无法拆分时在集头标注“超长镜头待拆”。

### 3. 镜头语言

统一术语：

| 中文 | 缩写 |
|---|---|
| 全景 | WS |
| 中景 | MS |
| 近景 | MCU |
| 特写 | CU |
| 大特写 | ECU |
| 过肩镜头 | OTS |
| 低角度 | Low Angle |
| 荷兰角 | Dutch Angle |
| 主观镜头 | POV |

说明：原需求里“近景 (CU)”与“特写 (CU)”重复，本标准统一为近景 `MCU`、特写 `CU`。

### 4. 画面颗粒度

每个分镜段必须落实：

- 光影方向：逆光、侧光、顶光、冷/暖色温、亮部与阴影落点。
- 材质纹理：皮肤汗水、金属反光、织物褶皱、雪地冰晶、旧木纹理。
- 动态轨迹：推、拉、摇、移、跟、升降、环绕、手持、变焦的起止。
- 环境细节：天气、空气介质、使用痕迹、空间纵深。

### 5. “3+N”视觉平衡

- 每集 **3 个核心炫技镜头**，其余为 N 个正常叙事镜头。
- 正常叙事镜头约占 80%，炫技镜头约占 20%。
- 炫技位优先放在：情绪爆发、剧情反转、重要道具揭晓、空间转换。
- 类型可选：FPV 穿越、子弹时间、微距探针、极速推焦、瞳孔/镜面反射、希区考克变焦、荷兰角、速度斜坡、低角度冲击、环绕甩镜、震颤式手持。
- 项目字段 `shots[].showcase` 用于标记；不足 3 个时输出“炫技位·待定”，不得静默省略。

### 6. 六步公式（内部写作检查）

每个分镜段先在内部按六步拆解，最终合并成一段 `【画面详述】`：

```text
[主体] + [空间位置] + [动作/剧情] + [场景/环境] + [光影氛围] + [镜头语言]
```

- 主体：本段明确出现的人物、身体部位、道具；写清前景/中景/背景层次。
- 空间位置：场景、站位、朝向、距离、遮挡关系，以及上一段改变后的位置。
- 动作/剧情：连续可见动作链，不写心理活动。
- 场景/环境：地点、时间、天气、建筑、环境细节、空间方向。
- 光影氛围：光源方向、色温、光质、对比度、落在人物/道具上的结果。
- 镜头语言：景别、机位、运动、速度、焦点、景深、切点。

填充公式：

```text
[动作] = [主体部位] + [具体动词] + [速度/强度] + [路径与方向] + [可见结束状态]
[场景] = [地理位置] + [时间/天气] + [环境细节] + [空间方向] + [氛围]
[光影] = [光源方向] + [色温/色调] + [光质] + [对比度] + [人物/道具受光结果]
[镜头] = [景别] + [运动方式] + [速度] + [机位] + [焦点/景深] + [切点]
```

### 7. 视觉纯度

`【画面详述】` 只写摄影机拍得到的内容：

- 可以写：时间/天气/地点、人物外貌/服装/站位/朝向/遮挡、动作起点/路径/速度/结束状态、眉眼嘴角手指肩颈呼吸、景别/机位/构图/运镜/焦点、光源方向/色温/阴影/反射/雾雨雪、材质/色彩/画幅/清晰度。
- 不得写：台词原文、旁白、内心 OS、语气、音色、环境音、BGM、字数统计、剧情总结、情绪解释、人物动机、因果说明、“请生成/确保”等操作指令。
- 有台词时，画面正文只写嘴唇开合、停顿、视线、面部张力、手势和对方反应；台词进独立 `【台词】` 字段，格式为 `角色名：台词原文`。

### 8. 情绪转译

抽象情绪必须转成可见动作，至少落实两项：

```text
喜悦 → 嘴角上扬，眼神明亮，身体微微前倾，步伐轻快
愤怒 → 眉头紧锁，眼神锐利，手部紧握成拳，呼吸急促，身体紧绷
恐惧 → 瞳孔放大，眼神闪烁，嘴唇微颤，身体后缩，手指抓紧衣角
悲伤 → 眼神低垂，泪水滑落，肩膀轻微抖动，步伐沉重，表情麻木
克制 → 面部变化极小，肩膀稳定，只出现一次短暂视线变化或吞咽
压抑愤怒 → 下颌收紧，鼻息加重，手缓慢握拳，说话速度降低
决心 → 呼吸稳定，视线固定目标，重心向前，多余动作消失
```

优先使用“缓慢转身、轻轻抬手、脚步轻移”这类连续、自然、慢速度的动作描述，让画面更丝滑。

### 9. 连续性台账

写每段前内部记录，不输出给用户：

```text
场景与时间：
摄影机轴线与方向：
主光方向与色温：
人物起始位置和朝向：
前景/中景/背景：
道具位置与状态：
本段动作变化：
本段结束位置与状态：
```

下一段开头必须重申已经改变的位置、朝向和道具状态；不得瞬移、换手、换位或让道具状态跳变。

### 10. 镜头执行纪律

- 一个分镜段只保留 **一个主运镜**；不要同时推、拉、摇、移、环绕。
- 同一机位、同一画面角度不超过 5 秒；超过就切反应、插入、过肩、侧面双人或特写。
- 单画面清晰人物原则不超过 3 人；对话戏不超过 2 人。
- 每个分镜段结尾必须有可见结果：距离改变、视线改变、沉默、人物离场、群体反应、权力爆发或转场钩子。
- 建立地理必须在前，特写必须在后；对话段默认：空间双人/中景 → 说话者近景 → 听者反应 → 插入细节 → 反打 → 关系结果镜。

## 三、输出模板

```text
第 [X] 集：[本集标题]
本集总时长：[XX 秒]
炫技镜头：[3 个，列出分镜段编号与类型]

[集号-场序-镜号] [本段时长 / 累计时长] [景别] [机位/角度] [运镜]
【人物资产】：人物A（角色名｜角色ID）=[]｜人物B（角色名｜角色ID）=[]｜群演/婴儿=[]；没有的写“无”
【人物音色】：人物A（角色ID）=[]｜人物B（角色ID）=[]；无台词的人物也保留音色槽
【场景资产】：场景A（场景ID 场景名·时间）=[]｜场景B（场景ID 场景名·时间）=[]；闪回单独列
【道具资产】：道具A（道具名）=[]｜道具B（道具名）=[]；没有写“无”
【站位/轴线】：[谁在画面左/右、前/中/后景、朝向、距离、遮挡；180°轴线、视线方向]
【动作】：[主体部位 + 具体动词 + 速度/强度 + 路径/方向 + 可见结束状态]
【表情】：[眉、眼、嘴角、下颌、泪、吞咽、呼吸等可见微表情]
【情绪】：[压抑/爆发/恐惧/心疼/温柔/决绝等；只做表演依据，不写心理活动]
【景别/机位】：[WS/MS/MCU/CU/ECU/OTS/POV；Low Angle/High Angle/Dutch Angle/Eye Level]
【运镜】：[Dolly In/Dolly Out/Track/Orbit/Handheld/Whip Pan/Rack Focus/Static；速度、起止]
【焦段/景深】：[广角/标准/长焦/微距；浅景深/深焦；焦点落点]
【光影】：[Key/Fill/Rim/Backlight；方向、色温、光质、光比、亮部与阴影落点]
【台词】：角色名：[台词原文，一字不差；无台词写“无”]
【音效】：[环境音、动作音、特殊音效；写清触发点]
【BGM】：[动机/乐器/速度/强弱/进入与退出点；没有写“无”]
【视觉特效】：[UI、魔法、文字、色调转换、闪回处理；没有写“无”]
【画面详述】：[把以上信息合成一段可读的视觉描述；不写台词、不写心理活动；炫技镜头标注技术类型]
```

多角色连续对白按顺序逐行输出；同一角色被项目小镜拆开的台词，在同一个分镜段内合并回原文，但不得改动字词和标点。

### 资产槽规则

- 人物资产按本段**实际出现**顺序编号：人物A、人物B、人物C；群演、婴儿、照片/画像中的人物单独列。
- 每个有台词的人物都要有音色槽；本段无台词但后续会说话的人物，也可保留音色槽。
- 音色槽只放参考音频/文件路径；音域、音色、语速、情绪等设计参数放在集末“音色设计总表”，不混进画面提示词。
- 场景资产写“场景ID + 场景名 + 时间”；闪回、回忆、梦境单独建场景槽。
- 道具资产只列本段推动剧情或需要保持连续性的道具；不堆砌背景杂物。
- 所有等号后统一空方括号 `[]`，由使用者填入参考图/音频。

### 专业术语对照

| 类别 | 可用术语 |
|---|---|
| 景别 | WS 全景、MS 中景、MCU 近景、CU 特写、ECU 大特写、OTS 过肩、POV 主观 |
| 机位/角度 | Eye Level、Low Angle、High Angle、Dutch Angle、Top Shot、Worm's Eye |
| 运镜 | Static、Dolly In/Out、Track、Pan、Tilt、Orbit、Handheld、Whip Pan、Rack Focus、Zoom In/Out |
| 焦段/景深 | Wide-angle、Standard、Telephoto、Macro、Shallow DOF、Deep Focus、Split Focus |
| 光影 | Key、Fill、Rim、Backlight、Side Light、Top Light、Practical、Low-key、High-key、Chiaroscuro |
| 轴线/构图 | 180° Rule、Eyeline Match、Two-Shot、Profile Two-Shot、Foreground/Midground/Background、Negative Space、Frame-in-Frame |

## 四、语言风格

- 中文为主，英文术语只做辅助。
- 先分析情绪状态（压抑、爆发、嘲讽、希望），再写画面。
- 先建立空间关系（谁在左/右、前/后、朝向、遮挡），再写景别和运镜。
- 不写“大头贴”式孤立人物；每个画面都要有环境、光位和空间纵深。
- 画面详述里不写台词、不写心理活动、不写“请生成”等操作指令。

## 五、输出前检查

- [ ] 每个分镜段 4-15 秒，累计时间与集总时长一致。
- [ ] 每集恰好 3 个炫技段，类型明确；不足时标“待定”。
- [ ] 台词逐字一致，没有补字、改标点、拆句后丢失语气词。
- [ ] `【画面详述】` 只写可见内容，没有台词、OS、音效、心理活动。
- [ ] 每段有人物资产、人物音色、场景资产、道具资产四类空槽。
- [ ] 动作、表情、情绪、站位、景别、机位、运镜、焦段、光影、台词、音效、BGM 各自独立，不混写。
- [ ] 专业术语统一：景别缩写、机位角度、运镜英文、光位英文。
- [ ] 六步要素齐全：主体、空间、动作、环境、光影、镜头。
- [ ] 对话段先建地理，再给近景；轴线、视线方向连续。
- [ ] 一个分镜段只有一个主运镜；同一机位不超过 5 秒。
- [ ] 段尾有可见结果，能承接下一段。

## 六、与项目数据的关系

- `project.json` 的 `episodes[].shots[]` 仍是素材层，保留 0.5-30 秒的细镜。
- 导演分镜段由连续小镜按 4-15 秒重组；不改变原台词，不改变剧情顺序。
- 场景号 `场序` 按实际场景顺序；闪回、回忆单独建场。
- 资产清单仍由 `asset_manifest.md` 单独维护，不混进导演分镜正文。

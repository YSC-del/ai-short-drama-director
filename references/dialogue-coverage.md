# 对话场景覆盖与轴线规则

写对话戏分镜前读本文件。核心原则：**空间清晰度优先于华丽措辞**——观众（和 AI）必须先知道谁在左、谁在右、谁高谁低、什么隔在中间，再给特写。

---

## 一、对话台账（写分镜前内部建立，不输出给用户）

```text
场景/地点：
出场人物：
权力关系（谁求谁、谁怕谁、谁有筹码）：
摄影机轴线（A 与 B 的连线，摄影机只在这一侧）：
A 的位置与视线方向：
B 的位置与视线方向：
群体/背景位置：
固定锚点（家具、门、窗、道具的不变位置）：
关键道具/信息：
情绪转折点：
结束状态（距离/视线/姿态的变化结果）：
```

台账是内部工具。用户明确要求展示时才输出。

---

## 二、轴线规则（180 度规则）

1. A 与 B 的连线构成**轴线**。同一场对话的所有机位保持在轴线同一侧，A 永远在画面同一侧（如屏幕左），B 在另一侧。
2. **禁止无过渡越轴**。确需越轴时，用可见的环绕运动、中性正面镜头或角色走位穿过镜头来完成过渡。
3. 近景、特写、过肩都必须继承全景确立的左右关系。反打镜头（reverse shot）交换的是拍摄方向，不是人物位置。
4. 视线连续性：A 视线投向画面右，反打镜头里 B 的视线必须投向画面左。视线方向对不上 = 两人不在对视。

---

## 三、建置顺序：先地理，后特写

1. 对话的第一个镜头必须是能看清空间关系的镜头：双人镜头、全景或中景，说清**谁左谁右、谁高谁低、什么物体或空间隔在中间**。
2. 不要在第一个镜头就给特写——观众还不知道人在哪。
3. 后续近景、特写只在这个地理已经建立的段落里出现。

---

## 四、默认对话序列

```
空间双人/中景 → 说话者近景 → 听者反应 → 插入/道具细节 → 反打近景 → 关系结果镜
```

每一句重要台词，用三种功能之一覆盖，**至少覆盖一个**：

| 功能 | 作用 |
|---|---|
| 说话者镜头 | 谁在说、什么情绪说 |
| 听者反应镜头 | 这句话打到了谁、产生什么变化 |
| 插入镜头 | 台词提到的/藏着关键信息的道具（合同、手机、戒指、支票、伤口、门把手、剑柄） |

对话单元以**可见结果**收尾：距离改变、视线改变、沉默、一方离场、群体反应、权力爆发或转场钩子。不要用"下集更精彩"式旁白收尾。

---

## 五、四种覆盖模式

### 1. 普通双人对话（默认）

```text
1. 中景双人：A 屏幕左，B 屏幕右
2. 过肩：从 A 肩后拍 B
3. 反打过肩：从 B 肩后拍 A
4. 插入：手、杯、令牌、剑、袖口、眼睛
5. 干净单人大特写：给最强的那句台词
6. 关系镜：展示改变后的距离或沉默
```

### 2. 权力施压（审问、逼签、上位者对下位者）

```text
大全景/高低机位地理 → 权威者低机位或居中构图 → 弱势者轻微高机位
→ 听者反应 → 手/道具施压插入 → 距离改变后的双人镜
```

### 3. 情感坦白 / 秘密

```text
近双人 → 邋遢单人近景 → 眼部特写 → 手/袖口插入 → 听者沉默 → 背影或拉远收尾
```

### 4. 群体对峙

```text
群体大全景地理 → 孤立的主角 → 权威人物 → 人群反应 → 道具/手部细节 → 主角眼部特写 → 大全景结果
```

---

## 六、15 秒对话单元参考节奏

适用于一个连续剧情段落（对应一个**大分镜**）：

```text
0-2s   建立地点与左右关系
2-4s   说话者开口
4-6s   听者反应或道具插入
6-9s   情绪加压或指证
9-12s  近反应 / 手 / 眼 / 沉默
12-15s 结果镜或转场
```

节奏可按剧情伸缩，但**建立地理必须在最前，结果镜必须在最后**。

## 七、对话分镜检查清单

- [ ] 第一个镜头是否建立左右地理？
- [ ] 每个近景是否保持视线方向连续？
- [ ] 每句重要台词是否有说话者、听者或插入覆盖？
- [ ] 是否保持轴线（或越轴有可见过渡）？
- [ ] 每条生成的片段是否只有一个主运动？
- [ ] 锚点（家具、门、道具位置）是否重复足够多以保持空间稳定？
- [ ] 对话单元是否以可见的情绪或空间结果收尾？
- [ ] 单画面清晰人物是否 ≤2 人？

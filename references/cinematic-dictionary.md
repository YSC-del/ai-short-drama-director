# 电影镜头画面描述转换词典（精华）

用途：把剧本里的戏剧概念、导演术语、摄影术语，转换成视频生成模型能理解的**可见画面描述**。AI 不会自动把"压迫感""高级感""电影感"翻译成你脑中的画面——必须转译。

---

## 一、基本用法：每镜只选六个"一"

每个镜头优先选择：

```text
1 个戏剧关系 + 1 个构图方法 + 1 个光线逻辑 + 1 个主要人物动作
+ 1 个摄影机变化 + 1 种整体质感
```

**不要堆叠矛盾要求**："极浅景深"和"所有前后景都清晰"、"固定机位"和"摄影机持续环绕"、"自然写实"和"强烈梦幻炫光"——同一镜头里互相打架的要求必崩。

抽象概念一律转成五类可观察信息：① 人物在画面中的位置、大小与遮挡关系；② 人物做出的具体身体动作；③ 光落在人物、布景、背景上的实际结果；④ 摄影机从哪里看、是否移动、何时移动；⑤ 镜头开始和结束分别是什么状态。

## 二、戏剧概念 → 画面描述

| 戏剧概念 | 可直接用于 AI 的画面描述 |
|---|---|
| 压迫 | 低天花板压在头顶；强势者占大前景；弱势者被门框/家具限制在窄区；出口部分遮挡；画面大部处于阴影；摄影机缓慢靠近但不给人物留更多空间 |
| 孤独 | 固定大全景；人物只占很小面积；周围大量留白；与环境无互动；摄影机不靠近 |
| 疏离 | 两人分置画面两端，中间留明显距离或障碍物；稳定客观的中远景；很少对视；深景深让空间比表情更突出 |
| 亲密 | 眼平近距离双人镜头；两张脸在相近焦平面；无明显障碍；柔和侧光连接两人；只有轻微呼吸、视线与身体靠近 |
| 不安 | 构图略失衡；人物被挤向画面边缘；视线方向留出未知负空间；背景有细微难辨的运动；摄影机极轻微不规则漂移 |
| 权力 | 强势者居中或占大前景且保持静止；弱势者位于边缘/背景并不断调整位置；摄影机略低于强势者视线；构图稳定难以撼动 |
| 权力转移 | 镜头开始时 A 更大/更亮/更清晰；随事件发生，摄影机、焦点或光线逐渐转向 B；结束时 B 成为最大视觉重点 |
| 脆弱 | 人物处于较大环境中，身体轻微蜷缩或重心不稳；柔和但暴露细节的面部光线；周围缺少可依靠的物体；镜头足够近以看到微小反应 |
| 窥视 | 摄影机远离人物；窄视野；人物被模糊前景、门缝、窗框、家具部分遮挡；像从另一个房间观察 |
| 秘密 | 关键信息在阴影、遮挡或画面边缘；人物通过视线、手部或道具暴露信息；镜头延迟揭示完整内容 |
| 秘密暴露 | 人物原本在阴影/背景；秘密被说出时走入光中、焦点转向人物或摄影机缓慢推近；结束时人物无法继续隐藏 |
| 犹豫 | 人物开始动作后中途停下；手已接近物体但没触碰；回答前吸气或短暂停顿；视线在目标与出口之间移动一次 |
| 宿命 | 构图稳定、对称或封闭；人物沿预先存在的线条移动；摄影机缓慢且不可逆；环境大于人物，结局似乎早已存在 |
| 释然 | 身体从紧绷逐渐放松；视线不再回避；画面空间变得开放；摄影机停止推进或轻微拉远；阴影密度降低 |
| 悲剧预感 | 场景表面平静，但构图存在过大负空间、即将熄灭的光源或孤立道具；摄影机停留略长；人物尚未意识到危险 |
| 温暖安全 | 人物靠近画面中心或彼此靠近；暖色实景光源覆盖皮肤；阴影柔和但有层次；背景有稳定生活细节；摄影机平稳缓慢 |
| 真实感 | 自然身体惯性；动作之间有停顿；不持续做表情；环境有轻微不完美和使用痕迹；光源有现实来源；摄影机不刻意炫技 |

## 三、表演概念 → 身体动作（情绪转译）

永远不要只写"她很伤心""他很愤怒"。按五个维度转译：**面部细节 / 手部动作 / 身体姿态 / 视线方向 / 呼吸与节奏**。

| 表演概念 | 可见动作描述 |
|---|---|
| 克制 | 面部变化非常细微；肩膀躯干稳定；只出现一次短暂视线变化、轻微吞咽或呼吸变化 |
| 紧张 | 手指握紧道具；呼吸变浅；肩膀略僵；回答前停顿；视线快速检查出口后回到对方 |
| 心虚/撒谎 | 回答前停顿一拍；短暂看对方后立即移开视线；无意识调整衣角或握紧钥匙；身体想向前但最后停下 |
| 压抑愤怒 | 下颌收紧；呼吸通过鼻腔缓慢加重；手部不动或缓慢握拳；说话速度降低；不立刻靠近 |
| 爆发愤怒 | 突然缩短与对方距离；手臂幅度扩大；声音呼吸增强；有真实惯性；爆发后留短暂停顿 |
| 恐惧 | 重心向后；眼睛先于头部转向危险；呼吸暂停后加快；手寻找支撑；不敢完全背对威胁 |
| 悲伤 | 动作比正常更慢；想说话但先呼吸；视线停在某物体上；面部保持控制，泪水不是唯一表现 |
| 疲惫 | 肩膀下沉；动作开始前有短暂延迟；坐下时身体重量明显落下；眼睛更长时间重新聚焦 |
| 决心 | 呼吸逐渐稳定；视线固定目标；重心向前；动作变直接，没有多余小动作 |
| 权威 | 身体稳定；减少动作；延迟回应；让对方先填补沉默；目光持续但不过度用力 |
| 防御 | 双臂或道具靠近身体；身体侧转而非正面对；下巴收回；脚的位置准备后退 |
| 崩溃前夕 | 努力维持正常动作，但呼吸、手指或视线逐渐失控；说话停顿增加；身体仍未爆发 |
| 崩溃 | 克制的身体结构突然失去支撑；呼吸动作不再规律；需要依靠墙面、桌面或另一个人 |

常用参考（写台词动作时直接套）：

```text
喜悦 → 嘴角上扬，眼神明亮，身体微微前倾，步伐轻快
愤怒 → 眉头紧锁，眼神锐利，手部紧握成拳，呼吸急促，身体紧绷
恐惧 → 瞳孔放大，眼神闪烁，嘴唇微颤，身体后缩，手部无意识抓紧衣角
悲伤 → 眼神低垂，泪水滑落，肩膀轻微抖动，步伐沉重，表情麻木
```

**进阶**：优先用"缓慢转身、轻轻抬手、脚步轻移"这类连续、自然、慢速度的描述，让画面更丝滑。

## 四、动作 / 场景 / 镜头 / 光影的填充公式

```text
[动作] = [主体部位] + [具体动词] + [速度/强度] + [路径与方向] + [可见结束状态]
[场景] = [地理位置] + [时间/天气] + [环境细节] + [空间方向] + [氛围]
[光影] = [光源方向] + [色温/色调] + [光质] + [对比度] + [落在人物/道具上的效果]
[镜头] = [景别] + [运动方式] + [速度] + [机位] + [焦点/景深] + [切点]
```

例：`右手缓慢抬起，从桌沿滑向支票边缘，指尖压住纸角后稳稳捡起。`

## 五、光型的情绪用途（选光 = 选情绪）

| 光型 | 情绪/叙事用途 |
|---|---|
| 逆光/轮廓光 | 光环、不可及的romance、神圣感、分离、剪影 |
| 侧光 | 人格分裂、道德冲突、雕塑感面部、对峙 |
| 顶光 | 审判、压迫、审问、命运降临 |
| 底光 | 不安、危险、不稳定欲望 |
| 硬光 | 锐利阴影、残酷、暴露、对峙 |
| 软光 | 浪漫、温柔、怀旧、慰藉 |
| 低调光 | 神秘、痛苦、高对比、隐藏意图 |
| 高调光 | 天真、明亮、喜剧、开放情绪 |
| 黄金时刻 | 温暖、告白、温柔、回忆 |
| 蓝调时刻 | 分离、忧郁、悬置的时间 |
| 窗光 | 私密告白、内在渴望、可读的皮肤质感 |
| 百叶窗/格窗光 | 秘密、禁忌欲望、猜疑 |
| 门缝光 | 门槛、发现、危险进入 |
| 屏幕光（手机/电视） | 深夜私密情绪、秘密、数字亲密 |
| 烛光/火光 | 亲密、脆弱、旧世界浪漫、不稳定阴影 |
| 霓虹侧光 | 都市欲望、暧昧、诱惑、夜生活 |
| 车灯/车尾灯 | 短暂相遇、追逐、深夜压力 |
| 月光/星光 | 冷距离、孤独、童话般脆弱 |
| 雨/雾/雪 | 光的质感；雨=破裂，雾=不确定，雪=安静的脆弱 |

女频短剧光线快捷方式：克制隐忍=硬侧光+低调；破碎泪感=冷轮廓光+泪部高光；甜宠温存=黄金时刻+柔逆光+暖调发丝光；暧昧诱惑=霓虹轮廓光+唇部高光+焦外光斑；宿命对立=分割光（一暖一冷）；病弱守护=冷顶光+苍白皮肤；清冷易碎=月光+银轮廓光+蓝灰调；文艺暗恋=台灯实景光+空气中灰尘光束+浅景深。

## 六、空泛词改写（禁用 vs 改写）

| 空泛词 | 改写方向 |
|---|---|
| 电影感 | 明确景别、空间层次、人物大小关系、光源方向、明暗比例、运镜触发点和结束构图 |
| 高级感 | 视觉重点单一；色彩种类受控；材质真实；高光柔和；运动克制；背景无无关元素 |
| 戏剧性 | 让人物关系、光线或构图在镜头中发生明确变化，而不是只加高对比和饱和色 |
| 大师级摄影 / 好莱坞质感 | 删除该词；改写成具体机位、构图、光线、焦点、运动结果 |
| 文艺片感 | 固定或缓慢机位；克制表演；较长停留；环境声清楚；构图保留负空间；低饱和 |
| 史诗感 | 人物尺度远小于环境；地形/建筑巨大纵深；摄影机缓慢升高或拉远 |
| 梦幻 | 缓慢动作、柔和高光扩散、薄雾、低反差、略非现实的空间关系；主体保持清楚 |
| 恐怖 | 先明确未知空间、遮挡、画外声音、光线缺失、延迟揭示；不要只写黑暗血腥 |
| 浪漫 | 人物距离缩短；视线与动作节奏同步；柔和侧光；背景细节减少；摄影机缓慢靠近 |

## 七、正向约束词库（视频模型对否定句执行不稳定）

主提示词描述"**应该保持什么**"，而不是反复写"不要什么"；负面词统一走负面提示词通道（`build_prompts.py` 自动拼装）。

| 想避免的问题 | 推荐正向约束 |
|---|---|
| 摄影机乱动 | 摄影机安装在固定三脚架上，全程保持完全相同的位置、方向和构图 |
| 人物乱动 | 人物从开始到结束保持坐姿静止，只有呼吸和一次缓慢转头 |
| 背景蠕动 | 家具、墙面、门窗和灯具保持固定；只有窗帘边缘随风轻微移动 |
| 身份漂移 | 人物面容、年龄、发型、体型、服装和饰品在整个镜头中保持完全一致 |
| 道具变形 | 道具保持固定形状、材质、颜色和大小，始终位于人物右手 |
| 空间跳变 | 门窗、家具、灯具和人物之间的空间布局从头到尾保持一致 |
| 突然剪切 | 一个连续、无剪切、无跳帧的完整镜头，同一摄影机和同一空间 |
| 过度表演 | 自然克制的身体动作；面部变化细微；没有大幅手势；动作之间保留真实停顿 |
| 全画面都动 | 只有主要人物执行指定动作；次要人物和背景保持稳定 |
| 夸张虚化 | 中等景深，主要人物清楚，前后景仍可辨认 |
| 色彩随机变化 | 暖色只来自台灯，冷色只来自窗外；光源颜色和方向全镜稳定 |

## 八、镜头提示词组装器（九层，每层选一项）

```text
A 镜头身份：一段[时长]的[类型与基调]连续单镜头，[画幅]
B 场景与人物：[人物A]位于[画面位置与景深层次]，[人物B]位于[位置与层次]；
             [家具/门框/道具]在两者之间形成[连接、阻隔或方向]
C 视觉层级：观众首先注意到[第一重点]，随后发现[第二重点]，最后注意到[隐藏信息]
D 光线：[可信光源]从[方向]照来，使[亮部结果]；[阴影区域]保持[深度与细节]；
       背景呈现[亮度与颜色关系]
E 镜头与焦点：[焦段可见效果]；[景深范围]；焦点开始位于[对象A]，在[触发事件]后转向[对象B]
F 人物动作：镜头开始时[初始状态]。首先[动作一]，随后[动作二]；
          人物通过[眼神、呼吸、手部、重心]表现[状态]
G 摄影机运动：摄影机最初[固定或运动]。当[事件]发生时，沿[轨迹]以[速度]
            移动[距离/角度]，最终停在[结束构图]
H 结束状态：镜头结束时，[人物、构图、焦点、光线和戏剧关系的最终状态]
I 稳定条件：人物身份、服装、空间布局、道具、光源方向和画面轴线保持一致。
           只有指定人物和环境元素运动。连续无剪切，动作符合真实重力和身体惯性
```

对应到本 skill 的字段：A=`duration_sec`+风格，B/C=`characters`+`scene_id`+`composition`，D=`lighting`，E/F=`action`，G=`camera`，H/I=`action` 的结束状态 + 约束（见 `references/prompt_recipes.md` 的中文导演版格式）。

## 九、炫技运镜库（视觉名场面专用）

每集 3 个（3+N 法则，见 `narrative.md` 第四节），标注 `shots[].showcase`。**一条片段只主打一个炫技运镜**，与叙事镜头交替；炫技用在情绪爆发、反转、重要道具揭晓、卡点这些节点。

| 类型 | 写法要点 | 适用节点 |
|---|---|---|
| FPV 穿越机运镜 | 摄影机像飞行器穿过窗框、门缝、桌椅之间；轨迹明确（从哪里进、从哪里出）；终点必须落在主体或关键道具上 | 追逐、登场、空间揭示 |
| 子弹时间 | 主体动作（挥拳、落杯、转身）在瞬间冻结或极慢，摄影机围绕主体弧线运动；背景保持正常速度差 | 打脸、逆转、击碎瞬间 |
| 微距探针 | 摄影机贴着表面滑行（桌面、地面、皮肤），极浅景深；沿途揭示 2-3 个信息点，终点是主体 | 道具揭秘、情绪铺垫 |
| 极速推焦 | 从大景别在 1 秒内推到眼部/关键道具；背景强烈拉伸模糊；落幅必须稳 | 震惊、识破、卡点 |
| 瞳孔/镜面反射 | 用瞳孔或镜面、屏幕、水洼的反射呈现另一空间/另一人物；反射画面必须清晰可辨 | 回忆、暗示、身份揭露 |
| 希区考克变焦 | 推机位同时拉广角（或反之），主体大小不变、背景剧烈伸缩；产生眩晕与心理失衡 | 恐惧、崩溃、真相时刻 |
| 荷兰式构图 | 地平线倾斜 15-30 度；只在心理失衡或危险升级时使用，单集 ≤1 次 | 不安、对峙、失控前奏 |
| 速放慢放切换 | 动作先正常速度，触发事件后瞬间慢放再恢复正常；切换点必须有明确触发 | 命中、落泪、翻盘 |
| 低角度冲击 | 摄影机贴近地面向上仰拍主体；主体占据画面上 2/3；脚步由远及近再有力量落地 | 登场、宣战、王者归来 |
| 环绕甩镜 | 摄影机快速绕主体半圈以上并按事件节点甩到新目标；运动中有方向性模糊，终点准确 | 反转、群体反应、惊艳亮相 |
| 震颤式手持 | 镜头跟随冲击事件轻微高频震动；震动幅度受控（可读、不晕），冲击后立刻稳定 | 撞击、枪声、耳光 |

**炫技镜头的三条纪律**：
1. 炫技也要完成叙事——运镜必须改变信息（揭示、强调、反转），不能为动而动。
2. 炫技镜头同样受小镜 1-5s、单镜 ≤30s、人物锚点一致约束。
3. 写英文视频提示词时，炫技只写进 `camera`/`action`（运动描述），不重复静态描述（否则改脸）。

# 题材、风格与自动配置

用户给一句话需求（"帮我做个悬疑短剧" / "重生复仇 + 国漫风"）时，按本文件流程自动产出全部制作参数。参数本体在 `assets/presets/`（脚本直接读取），本文件只讲**怎么选、怎么改、怎么组合**。

---

## 一、自动配置流程（四步）

1. **信号提取**：从用户输入中抓题材词、风格词、平台词、集数/时长词、目标观众词。
2. **题材匹配**：先精确匹配 `genres.json` 的 `aliases` / `keywords_en`；未命中则按语义映射到最接近题材，并在交付时显式说明"已默认使用 X 题材"。脚本兜底取 `production.json` 的 `default_genre`（默认 `underdog`）。
3. **风格裁定**：优先级 = 用户明确指定 > 从 brief 推断（`styles.json` 的 `aliases`）> 题材 `default_style`。用户要求"最好的/自动"时，用 `default_style`（即 `init_drama.py` 的实际行为）。
4. **参数推导**：由题材的 `episodes` / `episode_sec` / `pacing` / `reversal_every` 推导镜头数、反转节点、时长分配。

**关键规则**：任何自动推断都必须在一开始就告知用户，并允许一句"换成 X"覆盖。绝不在用户不知情的情况下静默决定题材方向。

## 三、参数推导规则

| 推导项 | 公式 |
|---|---|
| 单集镜头数 | `round(episode_sec / shot_sec)`，shot_sec 由 pacing 决定：slow=4.5、medium=3、fast=2 |
| 单镜时长 | 0.5-30 秒（硬约束）。长镜头（>10s）每集最多 1 个且不进第 1 集 |
| 大反转集 | 第 1、3、6、9、12…集（`reversal_every` 的倍数集，含第 1 集） |
| 每集钩子数 | fast=2、medium=1-2、slow=1（钩子≥1 是硬要求） |
| 对白占比 | slow≤40%、medium≈50%、fast≤35% |
| 空镜数量 | 每集 1-2 个，只放在转场或情绪落点 |
| 主要角色数 | 短剧 ≤5 人（AI 生成下每多 1 人，一致性风险成倍上升） |
| 场景复用 | 全剧场景 ≤ 12 个；场景越少，画面一致性越好 |

**题材专属创作弹药**：写大纲与分集前，先读该题材在 `genres.json` 里的这几个字段——`core_drive`（核心驱动力链）、`pleasure_points`（爽点清单）、`hook_types`（钩子类型）、`key_props`（关键道具）、`emotion_curve`（情绪曲线）。分集的爽点、钩子、道具从这些字段里取，不要凭空另想。

## 四、风格裁定细节

`styles.json` 共 **26 种视觉风格**。Agent 可直接消费的字段：`camera`（该风格的运镜倾向）、`consistency`（该风格的一致性策略）、`lighting`（缺省光型，`build_prompts.py` 自动回落）；`prompt_suffix_*` 与 `negative_extra_*` 由脚本拼装——画风与色彩信息已内含在前两者里，不单独设字段。

裁定原则：

- **风格必须与题材匹配**：水墨 × 修仙、黑白 × 悬疑、韩系 × 甜宠。跨风格组合（"水墨 + 赛博"）只在用户明确要求时使用，且要在提示词里把两种 token 都写清楚，并抽 1-2 张测试图确认效果再批量。
- **风格一致性优先于单张好看**：一个 skill 里最容易翻车的是"风格漂移"。全剧只允许一个 `prompt_suffix`，禁止中途更换。
- **换风格 = 换 `prompt_suffix`，不是换人物描述**：人物锚点短语必须跨风格保持稳定，否则同一个角色会变成两个人。
- **真人风格三选一时按平台与题材定向**：现代都市真人（职场/复仇）> 古代真人（宫斗/武侠）> 末日真人（末世/科幻）；欧美中世纪真人只配西幻与神话。

## 五、平台参数联动

平台决定竖屏安全区与字幕样式（`production.json` 的 `platforms`）。规则：

- 未指定平台 → 默认 `douyin`；平台词按 `platforms[].aliases` 识别（抖音/douyin、B站/bilibili、视频号 等）。
- 平台影响的是**合成阶段**（分辨率、安全区、字幕字号、响度），不影响创作阶段。
- 竖屏构图注意事项见 `references/shot_language.md`。

## 六、禁用与降级

每个题材的 `taboo` 是硬约束。命中时必须改写情节，不能只模糊画面。改写优先级：

1. 改变动作本身（把血腥场面改成"镜头外 + 声音 + 表情"）
2. 改变责任归属（让行为在剧内被批判而不是被奖励）
3. 改变结果（让违规行为付出代价）

降级无效时，换题材方向而不是硬做。详见 `references/compliance.md`。

# 模型适配指南

`build_prompts.py` 产出的提示词是通用格式；贴到具体工具前，按下表做最后一公里适配。
工具版本迭代快，具体参数以工具内实际选项为准；本文件只固化**结构性**差异，不编造具体参数值。

---

## 一、提示词语言与模式选择

| 你的情况 | `meta.prompt_lang` | `meta.video_workflow` | 说明 |
|---|---|---|---|
| 国内工具（剧梦 / 即梦 / 可灵 / 海螺等） | `zh`（默认） | `i2v` 或 `t2v-ref` | zh 模式提示词中英混排（锚点中文 + 50mm 镜头参数），直接可用 |
| 海外工具（Runway / Kling 国际版 / Veo / Sora 等） | `en` | `i2v` | 跑 `build_prompts.py --strict-en` 保证纯英文；需补 `action_en` / `video_action_en` / `lighting_en` |

改模式后必须 `build_prompts.py --force` 重建提示词（两套格式不通用）。

## 二、图片生成（角色定妆照 / 场景定妆照 / 分镜首帧）

通用纪律（所有工具适用）：
1. **画幅选 9:16**。提示词已自动带画幅 token（双保险），工具里也要选。
2. 定妆照、场景定妆照、首帧图**统一同一工具生成**，避免工具间画风差异。
3. 支持 seed 的工具：同角色固定同一 seed，记入角色卡。
4. 支持垫图/参考图的工具：传定妆照（人物）或场景定妆照（场景），权重中等。
5. 负面词照抄清单里的负面词栏，不要增删。

按产出物选工具能力：
- **定妆照（复合布局）**：需要"一张图内多主体"能力强的模型；布局崩（三视图长脸/两张大头照）时，退回分图生成——先大头照，再三视图，人工拼图。
- **场景定妆照**：无人物空场景，任何工具可出；关键是**同一场景所有镜头共用这一张**作风格/空间基准。
- **分镜首帧**：逐镜生成；同一场景连续镜头加传场景定妆照作垫图，空间更稳。

**首帧 QC 通过后先放大再进视频**：`python scripts/enhance.py --upscale`（见 production.md 素材增强节）。

## 三、视频生成

### i2v 工作流（默认）

| 步骤 | 操作 |
|---|---|
| 1 | 首帧图（放大件 `-2x`）上传为首帧 |
| 2 | 视频提示词照抄（只含运动，**不要**把静态描述补回去） |
| 3 | 负面词贴入负面词栏（无负面栏的工具忽略） |
| 4 | 时长设为镜头 `duration_sec`；工具固定档位（5s/10s）时选 ≥ 设定值的档，成片阶段裁剪 |
| 5 | 运镜幅度档位选"小/低"（有此选项时）；本 skill 的运镜词已按克制写法生成 |

**单镜纪律**：一次一镜。失败（脸崩/漂移/乱动）立即降运动幅度重抽，不要连续抽 3 次以上同参数。

### t2v-ref 工作流（剧梦"文生视频 + 参考图"类）

1. 参考图传**人物定妆照**（不是首帧图）；多角色镜头传对应角色的定妆照。
2. 提示词整条照抄（已含静态层 + 表情/台词/音效/BGM/特效标签段）。
3. 台词口型：工具支持台词驱动口型时，提示词里的 `台词：` 段自动生效；不支持时删掉台词段、改用后期配音对口型。

### 尾帧与长镜头

- 需要下一镜接续时：`python scripts/enhance.py <上一镜视频> --last-frame` 提取尾帧 → 作下一镜首帧。
- 尾帧**必须从视频导出**，重新生成必跳变（prompt_recipes.md 第五节）。

## 四、配音 / 音乐

- **TTS**：audio_prompts.md 的每镜配音提示词（音色/语速/情绪）+ 台词原文。同一角色全剧同一音色参数。
- **BGM**：audio_prompts.md 每集一条 BGM 提示词，直接贴给音乐生成工具（如剧梦音乐 / Suno 类）；时长按提示词，生成后截取。

---

## 五、常见工具差异速查

| 差异点 | 处理 |
|---|---|
| 提示词长度限制（如 500/2000 字） | 保留前段：锚点 → 场景 → 景别 → 画幅 → 动作；画质后缀可截断（影响最小） |
| 无负面词栏 | 忽略负面词清单；主提示词里**不要**手动补否定句 |
| 运镜档位（固定几档） | 按提示词首个运镜词选最接近档（固定→static，推→push in，跟→follow） |
| 概念不符被拒（人物过审类） | 查 `references/review_rules.md` 替换指南改写；不要试图绕过卡审词库 |
| 中文工具理解英文 token 差 | zh 模式下锚点用中文重写（`characters[].image_prompt` 改中文，全剧逐字一致仍成立） |

## 六、一致性三方案对照（详见 prompt_recipes.md 第六节）

| 方案 | 工具要求 | 何时用 |
|---|---|---|
| A. 固定 seed + 锚点 | 支持 seed | 无参考图能力的工具 |
| B. 定妆照参考（首选） | 支持参考图/垫图 | 绝大多数现代工具 |
| C. 角色 LoRA / 角色 ID | 支持训练或角色库 | 长剧 / 平台自带角色库（如即梦数字人） |

选定后全剧不得切换方案。
